# Palette provenance

The RGB values in `src/palette.rs` are interoperability facts transcribed from LightBurn Software's public
“Color Palette” reference page (LightBurn documentation 2.2, accessed 2026-10-23):

https://docs.lightburnsoftware.com/2.2/Reference/UI/ColorPalette/

Only the 32 hexadecimal colour values for cut layers 00–29 and tool layers T1/T2 were used. No LightBurn code,
icons, screenshots, images, or prose is included.
